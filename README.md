# DVSC-S: Domain-Aware Validation & Semantic Confidence Scoring for Reducing LLM Hallucinations

## 📌 Overview

DVSC-S is an AI-powered hallucination detection and validation framework developed to improve the reliability and trustworthiness of Large Language Model (LLM) responses.

Large Language Models often generate factually incorrect or misleading information known as hallucinations. This project introduces a domain-aware multi-stage validation pipeline that verifies generated responses using semantic analysis, reference retrieval, and confidence scoring before presenting outputs to users.

The system combines response generation, domain classification, sentence-level verification, and semantic confidence scoring to reduce misinformation and improve factual consistency in AI-generated content.

# 🏗️ System Workflow

The proposed system follows a multi-stage pipeline:

## 1️⃣ Query Input
The user provides a query to the system.

## 2️⃣ Response Generation
The response is generated using:
- Google Gemini API (Primary)
- FLAN-T5 Model (Fallback)

## 3️⃣ Domain Identification
The generated response is classified into domains using:
- BART Large MNLI
- Zero-shot classification

## 4️⃣ Reference Retrieval
Relevant web references are retrieved using:
- Google Search
- Serper API
- Web scraping techniques

## 5️⃣ Sentence-Level Validation
Each sentence is validated against retrieved references using:
- Natural Language Inference (NLI)
- Semantic similarity analysis

## 6️⃣ Confidence Scoring
A semantic confidence score is calculated based on:
- Entailment score
- Reference support
- Validation consistency

## 7️⃣ Final Decision
The system produces:
- ✅ ACCEPT
- ⚠️ WARN
- ❌ REJECT
